# Conformal Calibration Pipeline
## Post-Hoc Conformal Calibration for Object Detection & Segmentation under Adversarial Conditions

### Project Structure

```
conformal_calibration/
├── configs/
│   └── dataset_config.py          # Dataset paths, URLs, split ratios
├── data/
│   ├── coco/                      # MS-COCO 2017 (download with download_datasets.py)
│   ├── voc/                       # PASCAL VOC 2012
│   └── raw/                       # Raw/intermediate data
├── src/
│   ├── datasets/                  # Dataset loaders and normalizers
│   ├── models/                    # Model wrappers (YOLO, DETR, SAM, Mask2Former)
│   ├── calibration/               # Conformal prediction methods (APS, RAPS, Two-Step CP)
│   ├── attacks/                   # Adversarial attacks (PGD, C&W, AutoAttack)
│   └── evaluation/                # Metrics (mAP, ECE, coverage, efficiency)
├── notebooks/                     # Jupyter notebooks for interactive analysis
├── outputs/
│   ├── eda/                       # EDA plots (generated by eda_pipeline.py)
│   ├── plots/                     # Experiment result plots
│   └── models/                    # Saved model outputs/predictions
├── download_datasets.py           # Dataset download + conformal split creation
├── eda_pipeline.py                # Full EDA with 8 publication-quality plots
└── README.md
```

### Quick Start

```bash
# 1. Install dependencies
pip install torch torchvision matplotlib seaborn pycocotools ultralytics

# 2. Download datasets (on machine with full internet)
python download_datasets.py --dataset coco --split val

# 3. Run EDA
python eda_pipeline.py

# 4. (Outputs in outputs/eda/)
```

### Dataset Pair Selection
- **Object Detection**: MS-COCO 2017 val (5K images, 80 classes, ~36K annotations)
- **Segmentation**: MS-COCO 2017 val (instance masks) + VOC 2012 (semantic seg, 20 classes)

### EDA Outputs
1. `01_class_distribution.png` — Class frequency + supercategory breakdown
2. `02_bbox_sizes.png` — Box area, W×H, aspect ratio, size categories
3. `03_spatial_heatmap.png` — Spatial center distribution (all/small/large)
4. `04_objects_per_image.png` — Density comparison COCO vs VOC
5. `05_confidence_analysis.png` — Confidence distribution + reliability diagram (ECE)
6. `06_cross_dataset.png` — Cross-dataset comparison
7. `07_conformal_split.png` — Calibration/test split verification
8. `08_longtail.png` — Long-tail analysis (crucial for class-conditional CP)
